PROMPTS USED FOR THE 2D GRAPHICS EDITOR C PROJECT
=================================================

Below is the chronological list of prompts and feature requests provided to develop and refine the 2D Graphics Editor C program:

Prompt 1: Initial Requirements
------------------------------
"Create a complete C program that implements a menu-driven 2D Graphics Editor using a 2D character array as the drawing canvas. Follow these requirements strictly:

1. Canvas Setup
   - Use a 2D character array as the drawing canvas.
   - Initialize the canvas with the character '_' (underscore).
   - Graphical objects should be drawn using the character '*' (asterisk).

2. Functions to Implement
   - Function to draw a circle.
   - Function to draw a rectangle.
   - Function to draw a line.
   - Function to draw a triangle.
   - Function to display the picture (print the 2D array to the console).

3. Menu-Driven Operations
   - Add objects to the picture.
   - Delete objects from the picture.
   - Modify objects in the picture.
   - Display the picture.

4. Implementation Details
   - Use modular functions for each shape and operation.
   - Ensure the program is menu-driven (user chooses options from a menu).
   - Use clear prompts for user input (coordinates, dimensions, etc.).
   - Deletion should restore affected cells back to '_' (underscore).
   - Modification should allow changing dimensions or position of an existing object.

5. Optional Enhancement
   - Integrate ncurses library to create menus and improve drawing/display if possible.

6. Submission Requirements
   - Code must be original and complete.
   - Daily push to GitHub repository is mandatory.
   - Final submission must include the GitHub repository link in Moodle.

7. Evaluation Rubrics
   - Copied code -> 0 marks.
   - No submission -> 1 mark.
   - Copied but submitted -> 2 marks.
   - Original but partially complete -> 3 marks.
   - Original almost complete -> 4 marks.
   - Original complete and functional -> 5 marks.

Deliverable: A fully working C program file (graphics_editor.c) with all required functions, menu-driven interface, and clear documentation in comments."
